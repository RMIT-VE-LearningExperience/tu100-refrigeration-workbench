# TU-100 component pilot

`tu100-component-pilot.blend` is an editable Blender scene. `build-pilot.py` recreates it and exports `public/models/tu100-component-pilot.glb` (about 201 KB). Generated with Blender 5.2.

This is an illustrative coil–observation tube–hand valve assembly, not a measured reconstruction of the RMIT unit and not a complete refrigerant circuit. All objects carry a validation note. Geometry is separated into coil frame/fins/path, glass, flanges, bolts, pipe, valve body, stem and handwheel. It deliberately does not map the generic pilot valve to a physical TU-100 valve ID or change emulator state.

The web `3D pilot` view loads the viewer on demand and supports orbit, zoom and component focus. The equipment photo and schematic remain available independently. No textures, external environment map or decoder downloads are required for the GLB. The web component dependency is bundled locally; the neutral environment is generated by the viewer.

Before expanding: measure dimensions, confirm all four physical tube positions, verify hidden pipework and valve IDs with the instructor, then conduct the comparative learner/tablet trial in the UX review. Add semantic component IDs only when their mapping is verified. Test glass appearance on target hardware. Performance has not yet been benchmarked on a physical classroom tablet.

References: https://docs.blender.org/api/main/bpy.ops.export_scene.html and https://modelviewer.dev/docs/index.html
